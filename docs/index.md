# DevOps for engineers

## About This Guide
As an engineering researcher, I write this guide by applying DevOps to streamline research workflows. Rather than focusing on precise theory, this note offers a pragmatic perspective on version control, deployment, code collaboration, and dependeny issue.

## Prerequisite
- [Install WSL](https://learn.microsoft.com/en-us/windows/wsl/install)
- [Linux basics](https://info-ee.surrey.ac.uk/Teaching/Unix/)
- Install [VS code in WSL](https://code.visualstudio.com/docs/setup/linux#_install-vs-code-on-linux) and [Gitlense](https://www.gitkraken.com/gitlens) add-on.
